Robinhood daily short interest — bookmarklet

Drag this link to your bookmarks bar:

Fetch RH short interest

To use it: open any signed-in robinhood.com page, click the bookmark. It fetches the last 92 days of modeled daily short interest for all 34 hoodlist tickers and downloads rh_si_YYYY-MM-DD.json — drop that file where the ingest script can find it (or leave it in Downloads; the daily job collects it).

The bookmarklet uses only the page's own signed-in session. It never shows, copies, or stores any token — it just saves the short-interest numbers.

Source: rh_si_bookmarklet.js in the same folder. Re-run build_rh_si_bookmarklet.py after any edit.
